# A study vault: how to set up Obsidian for note taking

One way to set up Obsidian so that taking notes in class, turning them into questions and revising
them takes as few steps as possible. **Paper: set up a study vault** (or *Settings → Lined Paper
Pages → Set up a study vault*) makes the folders, a folder for each
subject you pick (English, History, Science, Maths …), a Home page and a Cornell template; it only
makes what is not there yet.

## 1. Folders

```
Home                      your start page (pin its tab)
Subjects/
  RS/
    Beginning of Life/    one folder per topic
      Beginning of Life index     (Note: make an index of this folder)
      2026-11-12 IVF              one note per lesson
      2026-11-19 Abortion
  Science/
    …
Definitions/              one page per word (Alt+F makes it)
Quotes/                   one page per quote (Alt+O)
Diagrams/                 one page per diagram (Alt+M, Alt+I)
Cue cards/                cue card pages to print
Templates/                Cornell note
Attachments/              pictures you paste
```

- **A folder per topic**, not per lesson: the topic's notes, its index, and its cue cards
  (*Note: cue cards for every note in this folder*) stay together.
- **Name lesson notes by date and topic** (`2026-11-19 Abortion`): they sort in order.
- **Definitions and quotes have pages of their own**, so the same definition is used in every note
  that needs it, its revised versions are kept, and each one becomes a cue card by itself.

### Your subjects

- **Paper: subjects** (the bookshelf icon on the left): everything in the Subjects folder, beside the
  files, drawn exactly as your theme draws the file list (with AnuPpuccin's rainbow folders, each
  subject its own coloured section). A section for each subject, its topics and notes inside, and
  anything else you keep there (canvases, PDFs, pictures). Click a note to open it; right-click a
  folder for **New note** (a Cornell note from your template), **New folder**, or a subject's
  **Canvas**; Obsidian's own menu is there too.
- **Canvas** (the button at the top): a canvas of quick links with a page for each subject (its
  topics, its newest notes and a link to its own canvas); a subject's canvas has a page for each
  topic. Click a link to open the note. It is made again from the folders each time you open it from
  here; cards and arrows you add are kept.

(The folder of subjects: *Settings → Definitions, quotes and diagrams → Folder of your subjects*.)

## 2. The window

| Where | What | How |
| --- | --- | --- |
| Left sidebar | Files, search, bookmarks (bookmark Home and the topic you are on) | Ctrl+Shift+F to search everything |
| Middle | The note: **Live Preview** while you write, **reading view** to read, review and print | Ctrl+E switches |
| Right sidebar | **Cue cards beside the note** (Ctrl+Shift+B), **Outline** (the note's headings), **Backlinks** (where a definition or quote is used) | drag them into one sidebar, as tabs |
| Top of the note | The toolbar: Cornell ▾, Insert ▾, ✦ AI, ∑, pens, highlighters, ◯ marks, Review, Study, Cards ▾, ? | *Settings → Toolbar* |

Save it: *Workspaces* (a core plugin) → save as "Study", so it comes back the same.

## 3. Obsidian's own settings

- **Editor → Default editing mode: Live Preview**; **Readable line length: on**; **Spellcheck:
  English (UK)**.
- **Files and links → Default location for new notes: same folder as the current file** (a new
  lesson note goes in the topic's folder); **Default location for attachments: Attachments**.
- **Core plugins:** Templates (folder: Templates), Outline, Backlinks, Bookmarks, Workspaces,
  Page preview.
- **Hotkeys:** search "Lined Paper" to see or change every one (*Paper: hotkeys* lists them).

## 4. A lesson, start to finish

**Before (1 minute).** In the topic's folder, a new note named with the date and the lesson.
**Alt+L** (Insert: Cornell page): the title (today's date in its properties), the essential
question, a cue + notes group, the summary.

**During.** Write in the notes column; a new point is **Alt+N** (a new cue + notes group).
- A word to learn: **Alt+F** (a definition page, embedded). A quote: **Alt+O**.
- Colour as you go: blue pen for one view, red for another (**Ctrl+Alt+B / R**); highlight key words
  (**Alt+Shift+Y**).
- Maths and science: **Alt+=** for maths in the line ($v = \frac{d}{t}$), **Alt+S** for symbols
  (π ± ≤ → ⇌ Δ μ), *Insert: chemical formula* for H₂O and CO₂.
- An arrow: type `->`. A list that is a process or a comparison: select it, **Alt+M** (a diagram).

**After (10 minutes, the same day).**
1. Each line that matters: the cursor on it, **Alt+U**: a question in the cue beside it. Change it
   into your own words.
2. *Insert: summary from the cues and highlights*, then the summary in your own words.
3. Optional: **Alt+I** (Ask AI) for a diagram of the topic, or 5 practice questions as cues.

**Revise.**
- **Every day, 10 minutes: Ctrl+Shift+S (Study).** The cards due today: a card you know comes back
  in 1, 2, 4, 8 … days; one you don't, today.
- **Ctrl+Shift+R (Review):** the note with its notes covered (or its highlighted words blanked);
  answer each cue, click to check.
- **Before a test:** *Note: cue cards for every note in this folder*, then Export to PDF (A4, margin
  none) and print double-sided; and the topic's index page to see what you have.
